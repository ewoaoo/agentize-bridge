# 安全与限制

> [!WARNING]
> 当前**没有身份验证**。任何能访问端口的人，都能调用已注册的所有命令。如果没有明确的可信网络，请保持默认的 `127.0.0.1`。

## 已有的防护

`start_http()` 会自动启用两项校验：

| 校验 | 拦截对象 | 状态码 |
| --- | --- | --- |
| `Host` | DNS rebinding | `400` |
| `Origin` | 浏览器网页发起的跨站请求 | `403` |

允许的主机是 `127.0.0.1`、`localhost` 以及传给 `start_http` 的 `host`。

> [!NOTE]
> 自行使用 uvicorn 运行 `fastapi_app` 时，这两项校验**不会启用**。

## 注意事项

- **异常文本会返回给调用方。** 命令异常的消息会出现在 `500` 响应中，并被 AI 读取。异常类型和消息也可能出现在访问日志中，配置了 `log_file` 时会写入本地文件。异常信息中不应包含路径、密钥等敏感内容。
- **命令即权限。** 注册的命令即为对外开放的能力，应避免暴露可执行任意代码或读写任意文件的命令。
- **绑定非本机地址会向所有能访问该地址的人开放。** 在没有认证的情况下，任何可访问该地址的人均可调用命令。

## 暂不支持

| 能力 | 状态 |
| --- | --- |
| 身份验证 | 无 |
| TLS | 无 |
| 限流 | 无 |
| 流式输出 | 无 |
| 长任务 ID 与进度查询 | 无 |
| 返回值 Schema | 无 |

项目仍在快速迭代，部分功能可能不稳定，接口也可能调整。
